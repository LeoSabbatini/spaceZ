# spaceZ



App mobile simples para explorar os planetas do Sistema Solar, com informações de cada um.



## Funcionalidades



- **Tela inicial:** entrada do app

- **Lista de planetas:** todos os planetas em uma lista

- **Detalhe do planeta:** nome, descrição, tamanho, duração do ano, temperatura e posição em relação ao Sol



## Tecnologias



- [Expo](Expo — Build native apps with React) / React Native

- TypeScript

- Expo Router (rotas baseadas em arquivos)



## Pré-requisitos



- [Node.js](Node.js — Run JavaScript Everywhere) (versão LTS)

- npm

- Expo Go no celular, ou um emulador Android/iOS



## Como rodar



```bash

git clone GitHub - LeoSabbatini/spaceZ

cd spaceZ

npm install

npx expo start

```



No terminal, escolha como abrir o app: Expo Go, emulador Android, simulador iOS ou development build.
